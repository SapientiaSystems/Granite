# Providing Feedback

Use Provide Feedback in the [Help](content:granite/help-overview) center to report a defect, describe a problem, suggest an improvement or send kudos.

Choose a type, write a short summary and fill in the fields for that type. Your feedback is recorded with your user name.

Administrators review feedback in the Feedback view and track it from New to Sent to Received.
